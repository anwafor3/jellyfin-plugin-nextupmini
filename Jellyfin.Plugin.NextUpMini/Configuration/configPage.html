Next Up Mini

When an episode's end credits start, the web player shrinks the credits into a corner and counts down to the next episode. Changes apply the next time the web player is loaded (refresh the page).

How long the countdown runs before the next episode starts (3–60).
Used when an episode has no credits marker. 0 turns the fallback off.
Media segments (for example from Intro Skipper) are always used first.
When the credits marker ends well before the episode does, show "Skip to scene" instead of a countdown. Only turn this on if your credits markers cover the whole credits; partial markers or "next episode" previews cause false alarms.
